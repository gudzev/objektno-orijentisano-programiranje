# ShapeLab

## Kratak opis projekta

ShapeLab je program koji omogućava upravljanje geometrijskim oblicima
poput kvadrata, trougla, kruga i trapeza. 
Napravljen je kao projektni zadatak za predmet objektno-orijentisano programiranje.

Program ima sledece funkcionalnosti:
1. Dodavanje novih oblika
2. Ispis svih oblika zajedno sa ID-jem, povrsinom i obimom
3. Izmena oblika iz liste
4. Brisanje oblika iz liste  

Cilj projektnog zadatka bio je demonstracija principa objektno-orijentisanog
programiranja, poput enkapsulacije, apstrakcije, nasledjivanja i polimorfizma.

## Pokretanje programa

Za pokretanje programa, otvoriti command promt na racunaru.  
Zatim pronaci folder u kojem se nalazi ShapeLab.jar  
Potom izvrsiti komandu "java -jar ShapeLab.jar", nakon cega ce se program pokrenuti u konzoli.
